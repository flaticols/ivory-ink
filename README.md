# Ivory Ink for Zed

Ivory Ink is a restrained Zed theme with paired light and dark variants:

- `Ivory Ink Light`
- `Ivory Ink Dark`

The palette stays close to near-white and near-black surfaces, keeps contrast sharp on high-end displays, and uses a small sage / rose / cool-blue accent system for elegant syntax separation without visual noise.

## Install as a dev extension

1. Open Zed.
2. Run `zed: install dev extension`.
3. Select this directory.
4. Open `theme selector: toggle` and choose `Ivory Ink Light` or `Ivory Ink Dark`.

## Files

- `extension.toml`: Zed extension manifest
- `themes/ivory-ink.json`: theme family containing both variants
